# ต่อเกมเข้ากับ Google Sheet

เกมเป็นหน้าเว็บนิ่งๆ บน GitHub Pages จึงเขียนลง Google Sheet โดยตรงไม่ได้
ต้องมีตัวรับกลางคือ **Apps Script Web App** ซึ่งติดตั้งครั้งเดียวแล้วใช้ได้ตลอด

## ขั้นตอน (ทำครั้งเดียว ~5 นาที)

**1. เปิดสคริปต์**
เปิด Google Sheet ของเกม → เมนู **ส่วนขยาย → Apps Script**

**2. วางโค้ด**
ลบโค้ดตัวอย่างที่มีอยู่ทิ้ง แล้ววางเนื้อหาทั้งหมดจาก [`AppsScript.gs`](AppsScript.gs)

**3. จัดรูปแบบแผ่นงาน**
เลือกฟังก์ชัน **`setup`** แล้วกด **Run**
ครั้งแรกจะขออนุญาตเข้าถึง Sheet → กดอนุญาต (ถ้าขึ้นเตือน "ยังไม่ได้ยืนยัน" ให้กด
ขั้นสูง → ไปที่ ... แล้วอนุญาต)

จะได้แผ่นงาน 4 แผ่น จัดรูปแบบเรียบร้อย:

| แผ่นงาน | เก็บอะไร |
|---|---|
| สรุปภาพรวม | ตัวเลขสรุป คำนวณสดจากข้อมูลดิบ |
| ทุกคำตอบ | ทุกข้อที่นักเรียนตอบ พร้อมสิ่งที่เลือกและเฉลย |
| คะแนนสอบ | สอบก่อน/หลังเรียนรายด่าน พร้อมผลรายข้อ |
| เหตุการณ์ทั้งหมด | เข้าด่าน เก็บคริสตัล ผ่านเสาศิลา ปราบบอส ฯลฯ |

**4. เผยแพร่เป็น Web app**
กด **Deploy → New deployment** → ไอคอนเฟือง เลือก **Web app**

- Execute as: **Me**
- Who has access: **Anyone**

กด Deploy แล้ว **คัดลอก Web app URL**

**5. ใส่ URL ลงในเกม**
เปิด `index.html` หา `const SHEET_URL = '';` แล้ววาง URL ลงไป

```js
const SHEET_URL = 'https://script.google.com/macros/s/AKfy...../exec';
```

commit และ push แล้ว GitHub Pages จะอัปเดตให้เอง

**เช็คว่าใช้ได้:** เปิด Web app URL ในเบราว์เซอร์ ควรขึ้นว่า
`Lexicora พร้อมรับข้อมูลแล้ว` พร้อมวันเวลา

## ถ้าแก้โค้ดสคริปต์ภายหลัง

ต้อง **Deploy → Manage deployments → แก้ไข → Version: New version**
ไม่งั้นเกมจะยังเรียกเวอร์ชันเดิม

## เรื่องที่ควรรู้

**ข้อมูลไม่หายแม้เน็ตหลุด** — เกมเก็บเหตุการณ์ไว้ในเครื่องก่อน แล้วส่งเป็นชุดทุก 4 วินาที
ถ้าส่งไม่สำเร็จจะเก็บไว้ลองใหม่เรื่อยๆ และส่งอีกครั้งตอนปิดแท็บ
คิวจะถูกล้างก็ต่อเมื่อสคริปต์ตอบกลับว่าบันทึกสำเร็จจริงเท่านั้น

**ถ้าไม่ใส่ URL** เกมทำงานเหมือนเดิมทุกอย่าง คะแนนยังเก็บในเครื่องและหน้ารายงานครูยังใช้ได้
การต่อ Sheet เป็นของเสริม ไม่ใช่สิ่งที่เกมต้องพึ่ง

**ใครมี URL ก็ส่งข้อมูลเข้ามาได้** เพราะตั้งเป็น Anyone (จำเป็น เพราะนักเรียนไม่ได้ล็อกอิน)
ถ้ามีแถวแปลกปลอมให้ลบทิ้งได้ หรือถ้าต้องการความปลอดภัยมากขึ้นค่อยเพิ่มรหัสลับในภายหลัง

**หนึ่งเครื่องหนึ่งรหัส** — คอลัมน์ "รหัสเครื่อง" ช่วยแยกได้ว่าแถวมาจากเครื่องไหน
เผื่อมีนักเรียนชื่อและเลขที่ซ้ำกัน
